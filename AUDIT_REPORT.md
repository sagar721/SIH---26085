# FLOODWATCH — Repository Audit Report
Generated at the start of this session, before any changes. The repository itself was inspected directly (not prior reports).

## 1. Current Architecture (frontend)

React 19 + TypeScript + Vite 8 + Tailwind v4 + Zustand + MapLibre GL 6 + Framer Motion + lucide-react. Structure:

- **Stores**: `useZoneStore` (active pilot zone), `useUIStore` (modals + `viewMode`), `useSimulationStore` (timeline/scenario sliders), `useLayerStore` (layer visibility flags — **exists but is dead code wired only into `SettingsModal`, never read by `MapContainer`. Toggling a layer checkbox in Settings currently has zero effect on the map.** This is a real, pre-existing bug.)
- **Adapters**: `FloodDataAdapter` interface, `RealDataAdapter` (real OSM/MCGM/GSMaP data), `MockAdapter` (deterministic simulated flood/routing), combined via `useFloodData` hook.
- **Map**: `MapContainer` renders boundary/water/city-roads/buildings/pilot-roads/rainfall/flood/infra layers, camera driven by `viewMode` (`overview` vs `zone`) and `MUMBAI_OVERVIEW`/`PILOT_ZONES`.
- **Panels**: `TopBar`, `ZoneSelector`, `DashboardPanels` (rainfall + scenario sliders + `RoutingPanel`), `RightPanel` (risk summary + real affected-infrastructure list), `SimulationTimeline`, `AnalyticsModal`, `DataProvenanceModal`, `ValidationModal`, `SettingsModal`.

## 2. Critical Finding: Fabricated Content Violating the Data-Honesty Rule

Two components, present before this session's work, **display invented numbers as if they were real measured/validated results**, with no MOCK/SIMULATED labeling:

- **`ValidationModal.tsx`**: hardcoded CSI=0.84, POD=88.4%, FAR=11.6%, Depth RMSE=0.08m, NSE=0.89, plus fabricated "observed vs. simulated" water-mark comparisons for the 2005/2017/2020 Mumbai floods (e.g. "Sion Circle Water Mark — Obs: 1.45m, Sim: 1.41m, ✓ Error: -0.04m") complete with green checkmarks implying verified accuracy. **No such validation has ever been run** — no hydraulic model exists, no Sentinel-1/IFI comparison has ever executed (confirmed BLOCKED in `data/raw/validation/_SENTINEL1_STATUS.json` and `_IFI_ACQUISITION_STATUS.json`).
- **`AnalyticsModal.tsx`**: the "Pilot Zone Cross-Comparison" tab invents per-zone facts (elevation ranges, "88%/94% impervious surface ratio", named outfalls) with no source. The "Asset Vulnerability Breakdown" tab hardcodes five specific facilities with fabricated flood depths (e.g. "LTMG Sion Hospital — 0.85m, CRITICAL") presented as assessed fact.
- **`TopBar.tsx`**: "Coupled Model Live" with a pulsing green indicator — there is no coupled model; flood depth is a simple deterministic formula in `MockAdapter`.

These are flagged for correction as the highest-priority work this session, ahead of new feature work, per the task's explicit "Absolute Data Honesty Rule."
